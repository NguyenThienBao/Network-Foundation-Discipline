# HTML, CSS, and Javascript

## History

### HTML: The Foundation

HTML was created at CERN to help scientists share and link research documents across different systems. It was designed purely for structure, using "hypertext" to connect academic papers, making it the web's original digital filing system.

### CSS: The Design Layer

As the web grew, HTML’s lack of styling became a hurdle. CSS was introduced to separate content from design, allowing developers to customize layouts, colors, and fonts in a separate file. This made websites much easier to style and maintain without cluttering the structural code.

### JavaScript: The Engine of Interactivity

To move beyond static pages that only changed when refreshed, JavaScript was added to provide logic and movement. It transformed the web from a "read-only" experience into an interactive one, allowing for real-time updates, animations, and functional web applications.

### The DOM: The Universal Map

To stop the "Browser Wars" between companies like Netscape and Microsoft, the W3C standardized the Document Object Model (DOM). The DOM maps HTML into a consistent tree structure, giving JavaScript a universal way to interact with any browser reliably.
