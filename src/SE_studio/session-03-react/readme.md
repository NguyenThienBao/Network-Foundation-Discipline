# Session 03 - React

This session for training about ReactJS for Front-end development with Typescript

## 1 - Tech Stack

React : [https://react.dev](https://react.dev)

## 2 - Vite Tools

Vite is the build tools for the web.

Vite: [https://vite.dev](https://vite.dev)

* use ***npm***

```shell
$ npm create vite@latest
```

* use ***yarn***

```shell
# Install Yarn
$ npm install --global yarn

# install Vite
$ yarn create vite
```

## 3 - Create React Application with Vite and Typescript

* use ***npm***

```shell
$ npm create vite@latest <project-name> -- --template react-ts
```

* use ***yarn***

```shell
$ yarn create vite <project-name> -- --template react-ts
```

## 4 - Run React appplication

### 4.1 Install node-module

* use ***npm***

```shell
$ npm install 
```

* use ***yarn***

```shell
$ yarn install
```

### 4.2 Build and Run Project

* use ***npm***

```shell
$ npm run dev 
```

* use ***yarn***

```shell
$ yarn run dev
```
